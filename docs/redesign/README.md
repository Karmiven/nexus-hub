# Редизайн NexusHub — планы реализации

Три концепта глобального редизайна. Каждая папка содержит:

- `demo.html` — **эталонная статическая демка** (открой в браузере — это визуальный источник истины);
- `PLAN.md` — самодостаточное ТЗ для реализации (написано для передачи AI-модели или разработчику без контекста).

| Концепт | Папка | Суть |
|---|---|---|
| **A «Командный центр»** | `concept-a-command-center/` | Сайт как игровой лаунчер: боковая панель, экраны-вкладки, HUD-эстетика, неон циан+фиолет |
| **B «Аврора»** | `concept-b-aurora/` | Премиальный модерн: стекло (glassmorphism), аврора-градиенты, вкладки-пилюли сверху, бенто-сводка |
| **C «Терминал»** | `concept-c-terminal/` | По референсу владельца: угольный чёрный + янтарный акцент, бегущий тикер, гигантский заголовок NEXUS/HUB, моноширинные метки |

## Как работать с планом (промпт для модели)

Открой новую сессию на ветке от `main` (или текущей рабочей) и дай модели промпт вида:

> Реализуй редизайн сайта по плану `docs/redesign/concept-c-terminal/PLAN.md`.
> Эталон внешнего вида — `docs/redesign/concept-c-terminal/demo.html` (открой и изучи его CSS/разметку).
> Строго соблюдай раздел «Инварианты» плана. Иди по фазам, после каждой фазы прогоняй чек-лист.

## Общие сведения о проекте (для всех концептов)

- **Стек**: Node.js + Express 4, EJS-шаблоны, better-sqlite3, Socket.io, ванильный JS (без фреймворков и сборщиков).
- **Шаблоны**: каждая страница = `views/partials/header.ejs` + контент + `views/partials/footer.ejs`. Админка дополнительно включает `views/partials/admin-nav.ejs`.
- **CSS**: `public/css/style.css` (база + компоненты), `mobile.css`, `desktop.css`, `public/css/themes/*.css` — 6 тем, переключаются атрибутом `data-theme` на `<html>` и définюют CSS-переменные (`--bg-primary`, `--surface`, `--accent`, `--border`, …).
- **JS**: `public/js/main.js` — SPA-навигация (pjax: fetch + подмена `.main-content`), переключатель тем, мобильное меню, поллинг статусов; `public/js/translations.js` + `public/js/lang/*.js` — i18n через атрибуты `data-i18n` / `data-i18n-placeholder`.
- **Иконки**: Lucide (pinned `0.454.0`, unpkg) — `<i data-lucide="...">` + `lucide.createIcons()`.
- **Кэш-бастинг**: все ссылки на статику имеют `?v=<%= v %>`.
- **CSP** (server.js): разрешены `fonts.googleapis.com`/`fonts.gstatic.com`, `unpkg.com`, `cdn.jsdelivr.net`, `cdnjs.cloudflare.com`, инлайн-скрипты/стили разрешены.

## Инварианты (обязательны для ЛЮБОГО концепта)

1. **Логика не меняется**: маршруты, обработчики, БД, sockets, API — без изменений (кроме пунктов, явно разрешённых планом).
2. **Безопасность**: вывод пользовательских данных только через `<%= %>` (авто-экранирование EJS); в клиентском JS — `textContent`/`createElement`, не `innerHTML` с данными. CSRF: скрытое поле `_csrf` в формах и `<meta name="csrf-token">` в `<head>` должны сохраниться.
3. **i18n**: все новые/изменённые тексты — через `data-i18n` (+ добавить ключи во ВСЕ файлы `public/js/lang/*.js`: en, ru, ro, de).
4. **Темы**: механизм `data-theme` + CSS-переменные сохраняется. Новые компоненты стилизуются ТОЛЬКО через переменные, ни одного захардкоженного цвета в компонентных стилях.
5. **Админка остаётся рабочей**: если план не включает редизайн админки — она должна как минимум не сломаться (общие стили не должны уронить её вёрстку).
6. **Мобильная версия обязательна** (breakpoint ~880–900px, см. demo.html).
7. **Доступность**: видимый `:focus-visible`, `prefers-reduced-motion` отключает анимации, aria-атрибуты у интерактивных элементов.
8. **Без новых зависимостей** и без сборщиков — чистые CSS/JS/EJS.
9. Демки писались с системными шрифтами (CSP артефактов); **в проде шрифты подключаются с Google Fonts** — какие именно, указано в каждом плане.
