# План реализации — Концепт B «Аврора»

> **Эталон**: `demo.html` в этой папке — открой и изучи разметку/CSS.
> **Обязательно**: прочитай `docs/redesign/README.md` (общие сведения + «Инварианты»).

## Идея

Современный «премиальный» стиль (референсы: свежие SaaS-лендинги, лаунчеры): **анимированные аврора-градиенты** на фоне, **стеклянные карточки** (glassmorphism, backdrop-filter), крупные радиусы (18–26px), много воздуха. Навигация — **вкладки-пилюли** в плавающей стеклянной панели сверху. Главная — компактная: короткий hero с градиентным заголовком + **бенто-сетка** сводки (серверы, KPI, новости, превью чата). Обе темы равноценны — **светлая здесь ключевая фишка**.

## Дизайн-токены

Из `demo.html` (`:root` и `:root[data-theme="light"]`). Ключевые:

| Токен | Тёмная | Светлая |
|---|---|---|
| `--bg` | `#0e0b17` | `#f3f1fa` |
| `--glass` / `--glass-2` | `rgba(255,255,255,.045/.08)` | `rgba(255,255,255,.62/.9)` |
| `--stroke` / `--stroke-2` | `rgba(255,255,255,.09/.18)` | `rgba(60,45,120,.10/.22)` |
| `--brand` | `#9d7bff` | `#6d47e8` |
| `--brand-2` | `#46c8d8` | `#0d94a8` |
| `--pink` (доп. в градиентах) | `#e0699a` | `#c94e82` |
| `--ok`/`--bad`/`--warn` | см. demo | см. demo |

Аврора-фон: 3 размытых (blur 90px) цветных «пятна» `position:fixed`, медленный дрейф (`@keyframes drift`, 26s, alternate), отключается при `prefers-reduced-motion`. Плюс токены `--bg-glow-1..3`.

**Шрифты (Google Fonts)**: заголовки `Exo 2` (700–900), текст `Inter`; моно (`ui-monospace`) — только для адресов/цифр.

**Интеграция с 6 темами**: мост-алиасы в `style.css`:
```css
:root[data-theme] {
  --glass: color-mix(in srgb, var(--surface) 72%, transparent);
  --stroke: var(--border);
  --brand: var(--primary);
  --brand-2: var(--accent);
  /* glow-пятна — от primary/accent через color-mix */
}
```
Так каждая из 6 тем автоматически перекрашивает стекло и аврору. Проверить `color-mix` (все современные браузеры ок).

## Структура

- **Шапка**: логотип слева, справа — язык + «Войти» (стеклянные пилюли).
- **Вкладки** (sticky, стеклянная панель): Главная / Серверы / Новости / Чат / Мониторинг (+ Админ для админа). Это **обычные ссылки на существующие маршруты** — «вкладочность» визуальная, бесшовность даёт SPA-механизм `main.js`. Активная вкладка — градиентная заливка (по `res.locals.currentPath`).
- **Футер**: одна строка (© + подпись), лёгкий.

| Вкладка | Маршрут | Изменения бэкенда |
|---|---|---|
| Главная | `/` | ➕ SELECT'ы для бенто: серверы, 3 новости, 3 сообщения чата, счётчики |
| Серверы | `/servers` | нет |
| Новости | **новый** `/news` | ➕ маршрут + view (лента переезжает с главной) |
| Чат | `/community` | нет |
| Мониторинг | `/monitoring/dashboard` | нет |

## Фазы

### Фаза 1 — фон, токены, примитивы
1. `style.css`: токены + мост тем; аврора-фон (`.aurora` — вставить в `header.ejs` сразу после `<body>`); примитивы `.card` (стекло), `.btn-brand`/`.btn-glass`, `.pill` (статусы), метры.
2. Обёртка контента: `max-width: 1120px`. Радиусы: `--r-lg: 26px; --r: 18px; --r-sm: 12px`.

### Фаза 2 — шапка, вкладки, футер
1. `views/partials/header.ejs`: новая шапка `.top` + панель вкладок `.tabs` (sticky). Сохранить `id="themeSwitcher"`/`id="languageSelector"` (перенести в шапку как стеклянные пилюли) и `<meta name="csrf-token">`.
2. Активная вкладка по `res.locals.currentPath` (добавить в middleware server.js: `res.locals.currentPath = req.path`).
3. Счётчики на вкладках (`Серверы 4/5`, `Чат 3`) — опционально во 2-й итерации (нужен лёгкий кэш-запрос в middleware); в 1-й — без счётчиков.
4. `views/partials/footer.ejs`: однострочный футер. Логаут-форма (POST + `_csrf`) сохраняется — перенести в шапку рядом с «Войти» (кнопка «Выйти» для залогиненных).
5. Мобильная: панель вкладок скроллится горизонтально (`overflow-x:auto` уже в demo).

### Фаза 3 — главная (hero + бенто)
1. `routes/home.js`: добавить SELECT'ы (серверы, 3 сообщения чата; новости уже есть — ограничить 3).
2. `views/home.ejs`: hero по центру — бейдж живого статуса (`N из M серверов онлайн · X игроков`), заголовок с градиентным спаном (`hero_title`/`hero_subtitle` из настроек сохраняют смысл: title = первая строка, subtitle = абзац), 2 кнопки.
3. Бенто-сетка (3 колонки, см. demo): «Серверы» (широкая, строки `.row-srv`), «Сводка» (3 KPI), «Новости» (3 шт., клик — на `/news` или модалка), «Чат» (широкая, 3 последних сообщения, только чтение).
4. Старые hero-стили (glitch и пр.) и `games_list`-секцию с главной убрать; `games_list` можно вывести чипами на `/servers` (согласовать).

### Фаза 4 — внутренние вкладки
1. `/news`: сетка `.news-grid2` — закреплённая новость широкой карточкой (2 колонки: градиентная миниатюра + текст), остальные — по 3 в ряд. Модалка чтения — перенести текущий безопасный механизм (`encodeURIComponent` в `data-*`, вывод `textContent`), стекло `.mwin`.
2. `views/servers.ejs`: карточки `.srv-card` (иконка-градиент, пилюля статуса, адрес+copy при `show_ip_address`, прогресс при `show_player_count`, пинг).
3. `views/community.ejs`: панель чата `.chat2` — аватары-квадраты с инициалами (первая буква ника, градиентный фон по хэшу ника — маленькая JS-функция), бейдж «админ» НЕ вводить (у чата нет ролей) — в demo он условен; вход в чат/сокеты не трогать, только классы DOM и генерацию сообщений в JS.
4. `views/monitoring/dashboard.ejs`: карточки `.mon2` с метрами; поллинг не трогать.
5. Auth/setup/ошибки: стеклянные карточки по центру, кнопки `.btn-brand`.

### Фаза 5 — админка
Минимум — работоспособность. Опционально: стеклянные плитки статистики на дашборде админки.

### Фаза 6 — QA (чек-лист)
- [ ] Обе «родные» темы + все 6 старых тем: стекло и аврора перекрашиваются, текст читабелен (особенно светлая!).
- [ ] `backdrop-filter` деградирует достойно (fallback: непрозрачный `--surface` через `@supports not (backdrop-filter: blur(1px))`).
- [ ] SPA-навигация работает; активная вкладка обновляется после pjax-перехода (проверить `main.js`, при необходимости — обновлять класс вкладки в коде свапа).
- [ ] i18n en/ru/ro/de для всех новых строк; чат и формы работают; CSRF на месте.
- [ ] Мобильная 375px: бенто в 1 колонку, вкладки скроллятся.
- [ ] `prefers-reduced-motion`: аврора статична. Фокус видим. Консоль чистая.

## Явно НЕ входит
API/БД/sockets (кроме read-only SELECT'ов для главной), редизайн админки (опционален).
